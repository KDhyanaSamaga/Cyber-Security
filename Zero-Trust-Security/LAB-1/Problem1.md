# Problem Statement
### Date:10-08-2026

**A small company, Softtech Solutions, is setting up its network infrastructure with the network address 172.16.0.0. The company has three departments: Sales, Finance, and IT. They want to set up DHCP for automatic IP address assignment and configure DNS servers. They want to implement VLANs (Virtual Local Area Networks) and VLSM (Variable Length Subnet Masking). Each department should have its own subnet to isolate broadcast domains, improve security, and optimize network performance.
The IT department contains 300 computers, 120 computers are in Sales, and 50 computers are for the Finance department. Each department has only one device configured with a static IP address, acting as the manually configured appropriate DNS server using the domain www.softech.com
. Ensure that all hosts are updated with DNS information, and the DHCP server must be configured to assign IP addresses to the other hosts in all departments. The address for the DNS server (or Finance server) can be assigned manually on the router/switch. Inter-VLAN communication should be enabled with VLANs.**
