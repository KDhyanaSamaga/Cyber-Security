# Clone the repository
```bash
https://github.com/KDhyanaSamaga/Cyber-Security
```

# Navigate to LAB-3
```bash
cd Cyber-Security\AI-for-cybersecurity\LAB-3
```

# Create Virtual Environment
## If Windows
```
Python -m venv .venv
.venv\Scripts\activate
```
## If Linux/Mac
```bash
python3 -m venv .venv
source .venv/bin/activate
```

# Install the Library
```bash
pip install -r requirements.txt
```

# Run the Main File
```bash
python main.py
```
