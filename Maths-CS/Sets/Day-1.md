# Introduction to sets

## What are sets?
**A set is a collection of distinct, well-defined objects or items. In mathematics, a set is a well-defined collection 
of distinct objects, called elements or members.**
---
*Examples:*
```
A = {1,2,3,4}
B = {a,e,i,o,u}
```
### Important Points

- Each element appears only once in a set.
- The order of elements does not matter.
- For example, {1, 2, 3} and {3, 2, 1} represent the same set.
---
## Types of sets
- **Empty (Null) Set:** A set with no elements.
  - Example: ∅ or { }
- **Finite Set:** A set with a limited number of elements.
  - Example: {2, 4, 6, 8}
- **Infinite Set:** A set with endlessly many elements.
  - Example: {1, 2, 3, 4, ...}
